Add i32, u32 and bool value types (scalars and vectors) with Blender-like implicit conversions between them, plus new nodes: Compare, Switch, Boolean Math, Not, Any / All, Modulo, Negate, Bitwise, Bitwise Not, Bit Shift, To Float, To Integer, To Unsigned and To Boolean. Nodes can now expose enum settings, and handle shapes show the scalar kind.
