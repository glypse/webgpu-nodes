Add automatic layout to the Edit menu: Layout selected nodes, Layout document (the graph or node group in view) and Layout graph (every document of the project). Nodes are arranged in columns following their links, with crossings minimised along each node's sockets and every repeat zone kept together; the nodes keep their top-left corner. Layouts use the nodes' sizes as drawn.
