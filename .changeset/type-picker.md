Types are picked from one TypePicker menu everywhere (a node's type, adding or changing group and repeat-zone values): browsable submenus per kind (float, integer, unsigned, boolean) instead of long lists or grids. Group input/output values can now change type from the group sheet. On a node, the menu's first option is the type inferred from its links, shown as "[type] (inferred)" until another type is forced, which replaces the reset button.
