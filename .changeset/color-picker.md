Add a colour input control: it turns a vec3f / vec4f input (e.g. the Output node's) into a swatch opening a compact colour picker: wheel, value ramp, RGB, HSV or OKLch fields, alpha, hex and a screen eyedropper where the browser has one. Colours are stored as linear RGB; hex, HSV and swatches are shown sRGB-encoded.
