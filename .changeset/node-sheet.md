Every node has a sheet, opened with N or the faders button on the node: its first field is the node's label, which defaults to the node's own name and can be set per node (shown on the node and in the breadcrumb) and reset to the default. A group node's sheet also sets up its group, renamed “Group name” there, and a repeat zone node's sheet sets up its zone, replacing their separate sheets. Edit → Toggle node sheet opens the selected node's sheet.
