The add menu's search is fuzzy again: it finds names with letters skipped ("smst" finds Smoothstep) or with a typo ("smoth"), and highlights the letters matched. It also creates nodes with the options it names, several at once: "value vec2i" adds a Declare vec2i, "add vec3f" an Add of vec3f, "compare less" a Compare set to Less Than, "vorn man 3" a 3D Manhattan Fractal Voronoi.
