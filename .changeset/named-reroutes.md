Reroutes show their label above their dot: double-click a reroute (or press N) to name it. Check Hide links there to make it a named reroute: its links are drawn as short tags named after it on the inputs they reach (in full, dashed, while either end is selected; clicking a tag selects the reroute), so a value can be used anywhere without a link across the graph. To use one, drag a link out of an input and pick it in the add menu under Layout › Named reroutes, or add it on its own to get a reroute it feeds.
